How it works

What Claude actually receives

The playground is a tiny version of what n8n and the API do for you. Here is each part.

1. The prompt

This runtime has no system field, so the system prompt travels as the first message of every run. In the API and in n8n it goes in a separate system field, which the model treats as firmer ground rules.

2. The tools

Each tool is sent as a name, a description and a JSON schema for its inputs. Claude never sees the code. When it decides to call one, this page runs the function and sends the result back.

3. The loop

One run can take several rounds: think, call a tool, read the result, think again. The platform caps the rounds and makes the last one an answer. Each round costs a request.

4. The memory

Claude keeps nothing between runs. This page keeps the last N messages and sends them again each time. Set N to 1 and the agent forgets your name.
