# Source material

The course was written against two sources:

- The original five-day, fifteen-module professional syllabus, summarised in `content/syllabus.md`.
- MIT xPRO's *Designing and Building AI Products and Services* (lecture transcripts, workbooks and exercises). That material is copyrighted and is **not** included in this repository; the course text names the module whenever it borrows an idea. `BRIEF.md` lists which module informs which week.
